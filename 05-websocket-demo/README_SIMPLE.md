# 🚀 WebSocket聊天室 - 快速开始

> 3分钟上手WebSocket实时通信

## ⚡ 快速启动

```bash
# 1. 进入目录
cd 05-websocket-demo

# 2. 下载依赖
go mod download

# 3. 启动服务器
go run .

# 4. 打开浏览器
# 访问 http://localhost:8080
```

## 📝 简单使用

### 第一步：输入用户名
在页面输入框填入你的昵称（如"张三"）

### 第二步：点击连接
点击"连接"按钮，状态变为"已连接"

### 第三步：发送消息
- 在消息框输入内容
- 按 `Shift + Enter` 或点击"发送"按钮

### 第四步：测试多用户
- 复制当前网址
- 在另一个浏览器窗口打开
- 用不同用户名连接
- 开始多人聊天！

## 💡 主要功能

| 功能 | 说明 | 如何使用 |
|-----|------|---------|
| 💬 **群聊** | 所有人可见 | 直接发送消息 |
| 🔒 **私聊** | 仅指定用户可见 | 勾选"私聊模式"，选择对象 |
| 👥 **用户列表** | 查看在线用户 | 左侧边栏自动显示 |
| 📊 **统计信息** | 消息计数和在线时长 | 右侧信息面板 |
| 🔄 **自动重连** | 断线自动恢复 | 无需操作，自动进行 |

## 🎮 快捷键

- `Shift + Enter` - 发送消息
- `Esc` - 清空输入框

## 🐛 遇到问题？

### 连接失败
- 检查服务器是否在运行
- 确认端口8080没被占用
- 查看终端是否有错误信息

### 看不到消息
- 刷新页面重新连接
- 查看浏览器控制台（F12）
- 确认多个窗口使用不同用户名

### 服务器启动失败
```bash
# 检查Go版本
go version  # 需要 1.21+

# 重新下载依赖
go mod tidy
go mod download
```
