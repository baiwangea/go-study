## 🎓 学完这 7 关你会掌握

1. **Go 的第一原则**：一切都是拷贝，想改原件用指针
2. **方法接收者**：要改状态 → 指针；只读操作 → 值
3. **切片陷阱**：共享底层数组 vs 扩容后失联
4. **nil 的真相**：
   - nil map 写 panic
   - nil slice 能读写
   - 接口装 nil 指针后 `!= nil`
5. **逃逸分析**：返回局部变量地址为什么不会悬垂
6. **Go vs PHP 接口**：隐式实现 vs `implements` 关键字

## 🔧 常见问题

### Q: 为什么有 `//go:build level` 这行？
A: 允许同一目录有多个独立的 `main()` 函数，不会冲突。
   单独运行 `go run 文件名.go` 时会自动忽略这个标签。

### Q: 可以删掉 main.go 和 level/ 吗？
A: 可以！新模式下完全不需要它们。但保留也不影响学习。

### Q: 我想把代码改坏来学习，怎么恢复？
A: Git checkout 恢复，或者重新 clone 项目。

### Q: 思考题的答案在哪里？
A: 没有标准答案！**动手改代码验证**才是正确的学习方式。
   改出编译错误是好事，先读懂错误信息。

## 🎯 通关标准（整个模块）

能说清这三句话：

1. **Go 里所有赋值与传参都是拷贝**，想改原件就传指针
2. **切片 = (指针, len, cap) 三元组**，共享底层数组但可能在 append 后失联
3. **接口值 = (类型, 值)**，装了 nil 指针的接口不是 nil
