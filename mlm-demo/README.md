# MLM 分销奖励机制系统

> **Multi-Level Marketing 常见奖励算法演示项目**

## 📋 项目简介

本项目演示了多层级营销（MLM）系统中常见的12种奖励机制算法，包含完整的用户层级、职级管理和订单处理逻辑。

## 🎁 12种奖励机制速查表

| 奖项名称 | 英文/常用叫法 | 计算核心逻辑 | 依赖代数 | 依赖职级 |
|---------|--------------|-------------|---------|---------|
| **级差奖** | Differential | 自己比例 − 下级比例 × 业绩 | ❌ | ✅ |
| **推荐奖/直推奖** | Referral / Sponsor | 直接推荐人拿固定比例或金额 | 仅第1代 | 可选 |
| **越级奖/代数奖** | Override / Generation | 第2代及以后按固定比例拿 | ✅ | 可选 |
| **平级奖** | Peer / Same Rank | 同职级之间额外奖励 | ❌ | ✅ |
| **团队管理奖/领导奖** | Leadership / Management | 整条团队业绩 × 管理比例 | ❌ | ✅ |
| **见点奖/见单奖** | Point / Order Bonus | 每产生一单，上级拿固定金额 | ✅ | ❌ |
| **复购奖** | Repurchase | 老客户复购额外给推荐人奖励 | 仅直推 | 可选 |
| **育成奖/辅导奖** | Mentoring / Training | 下级达到同级或更高时给辅导人奖励 | ❌ | ✅ |
| **晋级奖** | Rank Advancement | 职级提升时一次性奖金 | ❌ | ✅ |
| **感恩奖/匹配奖** | Matching / Gratitude | 下级拿到的奖金再匹配一定比例 | ✅ | 可选 |
| **层奖** | Layer Bonus | 按层数给固定奖励（常见于矩阵） | ✅ | ❌ |
| **全局分红** | Global Pool / Dividend | 公司总业绩按职级权重分红 | ❌ | ✅ |

## 🎯 核心概念

### 1. 代数（Generation）

从推荐人向下计算的层级数：
- **第1代**：我直接推荐的人
- **第2代**：我推荐的人推荐的人
- **第N代**：依此类推

```
          我（推荐人）
           ├─ A（第1代，直推）
           │   ├─ A1（第2代）
           │   └─ A2（第2代）
           └─ B（第1代，直推）
               └─ B1（第2代）
```

### 2. 职级（Rank）

基于业绩、团队规模等指标的等级系统：
- **普通会员** → **VIP** → **经理** → **总监** → **合伙人**

不同职级享有不同的奖励比例和权限。

### 3. 业绩类型

- **个人业绩**：用户自己的订单金额
- **直推业绩**：第1代的订单金额总和
- **团队业绩**：整个团队（所有代数）的订单金额总和

## 💡 奖励机制详解

### 🥇 级差奖（Differential Bonus）

**适用场景**：鼓励职级提升，高职级拿更多比例

**计算逻辑**：
```
级差奖 = 订单金额 × (自己职级比例 - 下单人职级比例)
```

**示例**：
- 张三职级：总监（15%）
- 李四职级：VIP（5%），是张三的第3代
- 李四下单 1000元
- 张三级差奖 = 1000 × (15% - 5%) = 100元

**特点**：
- ❌ 不依赖代数（无论第几代都按职级差计算）
- ✅ 强依赖职级
- 适合直销、保险等行业

---

### 🥈 推荐奖/直推奖（Referral Bonus）

**适用场景**：奖励直接推荐行为

**计算逻辑**：
```
推荐奖 = 订单金额 × 固定比例（如10%）
```

**示例**：
- 张三直接推荐了李四
- 李四下单 1000元
- 张三推荐奖 = 1000 × 10% = 100元

**特点**：
- ✅ 仅限第1代
- 可选职级影响（可设置不同职级拿不同比例）
- 最常见的基础奖励

---

### 🥉 越级奖/代数奖（Override Bonus）

**适用场景**：激励团队深度发展

**计算逻辑**：
```
第2代：订单金额 × 5%
第3代：订单金额 × 3%
第4代：订单金额 × 2%
...
```

**示例**：
- 张三 → 李四（第1代）→ 王五（第2代）
- 王五下单 1000元
- 张三越级奖 = 1000 × 5% = 50元

**特点**：
- ✅ 依赖代数（从第2代开始）
- 可选职级影响
- 鼓励发展深度

---

### 🏅 平级奖（Peer Bonus）

**适用场景**：防止高职级躺赚，鼓励持续发展

**计算逻辑**：
```
如果下级达到与自己相同的职级：
平级奖 = 该下级团队业绩 × 平级奖励比例（如5%）
```

**示例**：
- 张三：总监
- 李四：总监（张三的下级）
- 李四团队本月业绩 10万
- 张三平级奖 = 100000 × 5% = 5000元

**特点**：
- ❌ 不依赖代数
- ✅ 强依赖职级
- 防止"压级"现象

---

### 👔 团队管理奖/领导奖（Leadership Bonus）

**适用场景**：奖励管理整个团队

**计算逻辑**：
```
团队管理奖 = 整个团队业绩 × 职级管理比例
```

**职级管理比例示例**：
- 经理：2%
- 总监：3%
- 合伙人：5%

**示例**：
- 张三：总监
- 张三整个团队本月业绩 50万
- 团队管理奖 = 500000 × 3% = 15000元

**特点**：
- ❌ 不依赖代数（整个团队统一计算）
- ✅ 强依赖职级
- 适合大团队管理

---

### 💰 见点奖/见单奖（Point Bonus）

**适用场景**：快速激励，每单都有收益

**计算逻辑**：
```
见点奖 = 固定金额 × 订单数量
```

**示例**：
- 每单固定奖励 10元
- 张三团队本月产生 100单
- 见点奖 = 10 × 100 = 1000元

**特点**：
- ✅ 依赖代数（通常限制在5代内）
- ❌ 不依赖职级
- 适合高频低价产品

---

### 🔄 复购奖（Repurchase Bonus）

**适用场景**：鼓励客户复购

**计算逻辑**：
```
复购奖 = 复购订单金额 × 复购奖励比例（通常高于首单）
```

**示例**：
- 李四是张三的直推客户
- 李四第2次购买 1000元
- 复购奖励比例 15%（首单只有10%）
- 张三复购奖 = 1000 × 15% = 150元

**特点**：
- ✅ 仅限直推
- 可选职级影响
- 适合消耗品、订阅制

---

### 🎓 育成奖/辅导奖（Mentoring Bonus）

**适用场景**：奖励培养人才

**计算逻辑**：
```
当下级达到与自己相同或更高职级时：
育成奖 = 一次性固定奖金
```

**示例**：
- 张三：总监
- 李四：经理 → 晋级为总监
- 育成奖 = 5000元（一次性）

**特点**：
- ❌ 不依赖代数
- ✅ 强依赖职级
- 一次性奖励

---

### 🚀 晋级奖（Advancement Bonus）

**适用场景**：庆祝个人成长

**计算逻辑**：
```
晋级奖 = 根据新职级给予一次性奖金
```

**奖金示例**：
- VIP → 经理：1000元
- 经理 → 总监：5000元
- 总监 → 合伙人：20000元

**特点**：
- ❌ 不依赖代数
- ✅ 强依赖职级
- 自己晋级自己拿

---

### 🤝 感恩奖/匹配奖（Matching Bonus）

**适用场景**：让上级分享下级的成功

**计算逻辑**：
```
感恩奖 = 下级获得的奖金总和 × 匹配比例
```

**示例**：
- 李四本月获得各类奖金共 10000元
- 张三是李四的上级
- 匹配比例 20%
- 张三感恩奖 = 10000 × 20% = 2000元

**特点**：
- ✅ 依赖代数（通常限制在3代内）
- 可选职级影响
- "奖金的奖金"

---

### 📊 层奖（Layer Bonus）

**适用场景**：矩阵制、裂变制系统

**计算逻辑**：
```
第1层：每人奖励 50元
第2层：每人奖励 30元
第3层：每人奖励 20元
```

**示例**：
- 张三的第2层有 10个人
- 层奖 = 10 × 30 = 300元

**特点**：
- ✅ 依赖代数/层数
- ❌ 不依赖职级
- 常见于矩阵制

---

### 🌍 全局分红（Global Dividend）

**适用场景**：让高层分享公司整体成长

**计算逻辑**：
```
1. 计算公司总业绩
2. 提取分红池（如总业绩的5%）
3. 按职级权重分配

权重示例：
- 总监：1份
- 合伙人：3份
- 董事：10份
```

**示例**：
- 公司月业绩 1000万
- 分红池 = 1000万 × 5% = 50万
- 总监10人、合伙人5人、董事2人
- 总权重 = 10×1 + 5×3 + 2×10 = 45份
- 每份 = 50万 ÷ 45 = 11111元
- 某总监分得 = 11111元

**特点**：
- ❌ 不依赖代数
- ✅ 强依赖职级
- 长期激励手段

## 📚 学习路径

1. **基础概念** → 理解代数、职级、业绩类型
2. **单一奖励** → 从推荐奖开始，逐个理解算法

4. **实战应用** → 根据业务需求选择合适的奖励组合

## ⚠️ 注意事项

1. **法律合规**：MLM在很多国家有严格监管，务必确保合法合规
2. **透明公开**：奖励规则应该对所有参与者公开透明
3. **防止欺诈**：需要有完善的反作弊机制
4. **数据隐私**：妥善保护用户数据和财务信息
